## Your Mac. Your storage. Your choice.

| Tool | What it does |
| --- | --- |
| **Dashboard** | Keep backup plans, destinations and recent activity in view. |
| **Folder backups** | Choose Live, Snapshot or Archive Only, with Primary and Secondary destinations and retention you control. |
| **Restore** | Browse backups and retained archives, then recover a separate copy of the files you need. |
| **Storage Explorer** | See measured file and folder sizes, explore the folder map and find what takes up space. |
| **Cache Review** | Review unwanted application and developer caches, choose eligible contents and move them to macOS Trash. |

Cleanup moves selected eligible items to Trash first. Put them back while they remain there if needed; empty Trash separately when ready to reclaim the space. Apps may recreate caches.

**Free · macOS 13+ · Apple Silicon and Intel · No account needed.**

[Explore the features](https://www.elephantoapp.com/features) · [See the app](https://www.elephantoapp.com/inside-the-app)

## Local by design

Your backup contents stay on the storage you choose. No in-app usage analytics, telemetry or publisher-operated crash reporting. Automatic update checks are optional. Manual update checks, downloads, website links and storage services you choose can still use the network.
